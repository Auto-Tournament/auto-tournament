# Changelog

The release notes for each version of Auto Tournament are in two places, and they are the same notes:

- **[Changelog in the docs](https://docs.autotournament.gg/reference/changelog/platform)**: every version, newest first, including the hand-written notes for 2.x and earlier (then called MatchZy Auto Tournament).
- **[GitHub releases](https://github.com/Auto-Tournament/auto-tournament/releases)**: the notes, the Docker tags and the commits for each version.

3.0 is in beta. Until 3.0.0 ships, the `v3.0.0-beta.N` releases are the 3.0 notes. See [Upgrading to 3.0](https://docs.autotournament.gg/guides/upgrading-to-3).

The GitHub release is the source of truth. The docs changelog is generated from it, so this file does not repeat the notes.
